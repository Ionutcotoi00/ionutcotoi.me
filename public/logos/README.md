# Company Logos

Logo-urile companiilor sunt stocate aici și sunt afișate în secțiunea Experience.

## Fișiere existente:

- `bissoft.svg` - Logo pentru Bissoft S.R.L
- `diversework.svg` - Logo pentru DiverseWork Hub S.R.L
- `irum.png` - Logo pentru IRUM SA

## Format:

- SVG sau PNG (cu fundal transparent recomandat)
- Dimensiune: 64x64px sau mai mare (va fi redimensionat automat la 32x32px)
- Numele fișierelor trebuie să corespundă exact cu cele din `lib/data.ts`

## Notă:

Dacă un logo nu este disponibil sau nu se încarcă, va fi ascuns automat și se va afișa doar numele companiei.
